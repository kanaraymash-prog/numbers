1. Priemiro você entra na pasta projeto que você vai usar.
No coração dela coloca: 

cd ~/projetos/numbers
python3 -m venv .venv

2. Ativar o VENV no terminal:
source .venv/bin/activate

3. Mosstra onde está o python3 sendo usado:
which python

4. Apatir de agora as bibliotecas são baixadas no lugar certo:
pip install {BLA-BLA-BLA}

5. para sair do modo (.VENV):
deactivate

6. Atualizar o PIP (do venv):
pip install --upgrade pip

=============================================

7. Adicionar o PPA:
Instalador via PPA Oficial:
sudo add-apt-repository ppa:git-core/ppa

8. Atualizar lista de pacotes:
sudo apt update

9. Instalar e/ou atualizar o Git
sudo apt install git

10. Verificar a versão instalada:
git --version

11. Copiar uma pasta inteira de um canto para o outro:
cp -r /{URL}/ /{URL}/

Como criar o reposório a distância no github:

#1 Baixar o github CLI:
sudo apt install gh

#2 Autenticação (abre o navegador uma única vez para autorizar)
gh auth login

#3 Navegue até a opção HTTPS e insira o código do CLI:
! First copy your one-time code: 31A4-A8CE

#4.1 Depois de logado, criar o repositório dentro do projeto:
gh repo create numbers --public --source=. --push

#4.2 Garantir que o branch local se chama Main:
git branch -M main

#4.3 Enviar os commits:
git push -u origin main

4.4 Trazer o main de volta para o tal:
git reset --hard 00b29a5


git log --oneline -5
git status

4.5 Use esse comando para ter certeza que está na "main":
git branch --show-current

4.6 Para abrir o repostório no navegador:
gh browse

// PARA DELETAR UM REPOSTÓRIO DO GITHUB A DISTÂNCIA, E POR CLI

#5.1 Para deletar efetivamente:
cd ~/{URL local do seu projeto}/
// Exemplo: ~/Desktop/numbers

ou
gh repo delete {NOME DE USER}/{REPOSITORIO} --yes

gh repo delete kanaraymash-prog/numbers --yes
