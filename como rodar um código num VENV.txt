1. Priemiro você entra na pasta projeto que você vai usar.
No coração dela coloca: 

cd ~/projetos/numbers
python3 -m venv .venv

2. Ativar o VENV no terminal:
source .venv/bin/activate

3. Mosstra onde está o python3 sendo usado:
which python

4. Apatir de agora as bibliotecas são baixadas no lugar certo:
pip install {BLA-BLA-BLA}

5. para sair do modo (.VENV):
deactivate

6. Atualizar o PIP (do venv):
pip install --upgrade pip

=============================================

7. Adicionar o PPA:
Instalador via PPA Oficial:
sudo add-apt-repository ppa:git-core/ppa

8. Atualizar lista de pacotes:
sudo apt update

9. Instalar e/ou atualizar o Git
sudo apt install git

10. Verificar a versão instalada:
git --version

11. Copiar uma pasta inteira de um canto para o outro:
cp -r /{URL}/ /{URL}/

Ver em qual repositório vs está:
pwa

Ver os arquivos do repositório:
ls -la

Como instalar git em um repositório/ inicializar o repositório GIT:
git init

Configurar a idendtidade pela primeira vez:
git config --global user.name "Caua"
git config --global user.email "caua.louzeiro@sempreceub.com"

Verificar o STATUS de informações:
git config --list

//Criar o GitIgnore e configurar:
#1 - primeiro passo (criar o gitignore):
nano .gitignore

#2 - segundo passo (colar isso no nano):
.venv/
__pycache__/
*.pyc
.vscode/
.idea/
*.log
.env

// Fazer o primeiro Commit:
#1 
git add .

#2
git status  

#3
git commit -m "Commit inicial: projeto numbers"

// Atualizar o git:
#1 Veja o que mudou:
git status

#2 Adicionar as mudanças:
git add . 

#3 Comitar as mudanças:
git commit -m "Atualiza lógica de cálculo em bilion.py"

#4 ver o histórico de modificações:
git log --oneline

#5 Apague todos os arquivos do seu repositório e restaure para versão que funcionava:
git checkout {hash EM git log --oneline}
Exemplo: git checkout 5351731

#1 Ver todas as versões na história geral (não só a principal)
git reflog

#2 Restaurar para versão ferrada:
git reset --hard <hash-do-reflog>
Exemplo: git reset --hard 9836989

Como criar o reposório a distância no github:

#1 Baixar o github CLI:
sudo apt install gh

#2 Autenticação (abre o navegador uma única vez para autorizar)
gh auth login

#3 Navegue até a opção HTTPS e insira o código do CLI:
! First copy your one-time code: 31A4-A8CE

#4.1 Depois de logado, criar o repositório dentro do projeto:
gh repo create numbers --public --source=. --push

#4.2 Garantir que o branch local se chama Main:
git branch -M main

#4.3 Enviar os commits:
git push -u origin main
